# About Me

Hi👋, I'm Erika. Instead of using centralized social media, I've started my own blog to communicate with the world.

Topics will include:

- Sharing progress on projects
- What I'm learning
- Thoughts on tech and tech adjacent topics

## What is this site made with?

- [Fuwari](https://github.com/saicaca/fuwari) template for Astro
- GitHub for hosting
- Netlify for deployment
- VS Code for coding and managing Astro
- Obsidian to draft posts
- Notion for organizing notes and ideas
